# 2026-09-27

Release version: `2026.9.27`

## Changes

- TypeSpec contract authority is now an independent standard capability for
  APIs, events, configuration, commands, persisted interchange, worker
  protocols, and other Wavenumber-owned contract boundaries.
- Activity-oriented application architecture now defines typed input/results,
  stack composition, clean registration, frame-local state, leave decisions,
  cancellation, lifecycle, and native-host portability.
- Centralized backend guidance separates generated wire contracts, transports,
  semantic feature clients, stores, activities, and views, with decision rules
  for HTTP, SSE, WebSockets, and polling.
- Lit is the preferred component model for suitable new TypeScript
  applications. A canonical shell/theme reference demonstrates square ALX-style
  geometry, a gold-accent industrial palette, approved rotating backgrounds,
  JetBrains Mono, alternate themes, shell profiles, and token enforcement.
- `dev-std template list` and `dev-std template copy` expose version-matched,
  copy-owned TypeSpec and Lit activity templates.
- The new `contracts` and `application` audit capabilities validate declared
  authorities and application boundaries without executing arbitrary project
  commands.
- Repository architecture and build guidance now make self-application
  explicit, including direct TypeSpec/Lit development commands, live Vite
  review, clean-copy signoff, template resource packaging, and the boundary
  between the root Python CLI and its nested executable references.
- Headerless shell-profile previews now retain an explicit restore control, and
  native shell dropdowns follow the active dark or light theme for readable
  options.

## Validation

- Foundation tests cover TypeSpec and application audit diagnostics, capability
  summaries, template copying, schema declarations, and command inventory.
- The Lit template runs strict TypeScript, Biome and architecture linting, 38
  behavior/DOM tests, Vite production build, and dependency audit.
- Release signoff copies both templates into clean directories, installs pinned
  dependencies, audits their declarations, and executes their complete signoff
  scripts. The observed clean-copy runtime was approximately 60 seconds and is
  isolated in the release-facing <code>L99_006</code> lane rather than the
  focused policy loop.
- The approved background snapshots and JetBrains Mono files are cataloged as
  public reference assets with release inclusion, provenance, authorization or
  license, and checksum evidence.
- Stock-licensed backgrounds without explicit raw public-template
  redistribution evidence are excluded from the packaged reference.
- Full Rack signoff, package build, Twine validation, and installed-wheel
  template smoke testing are required before publication.
- Independent final review found no remaining implementation blockers after
  TypeSpec freshness, activity lifecycle, transport, style enforcement,
  template packaging, and installed-wheel findings were corrected.
