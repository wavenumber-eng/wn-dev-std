# 2026-08-11

Release version: `2026.8.11`

## Changes

- Expands the supported interpreter range from CPython 3.12 to normal
  GIL-enabled CPython 3.12 through 3.14.
- Runs the existing three-platform CI and release validation on Python 3.14
  without adding a Python-version job matrix.
- Keeps free-threaded Python builds outside the support contract until they
  receive dedicated compatibility evidence.
- Bounds Hatchling below 1.32 so release artifacts retain Core Metadata 2.4,
  which the current Twine release can validate.

## Validation

- Clean wheel-only installation and CLI smoke passed on CPython 3.12, 3.13,
  and 3.14 on Windows x64.
- `uv run --python 3.14 rack run --all` passed locally.
- `uv run --python 3.14 python -m build` produced the universal wheel and
  source distribution, and `twine check` passed both artifacts.
