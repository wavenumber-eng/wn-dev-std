# 2026-10-26

Release version: `2026.10.26`

This release fixes [#43](https://github.com/wavenumber-eng/wn-dev-std/issues/43):
Rust applications owning multiple local packages may declare one exact formatting
command such as `cargo fmt --package alx --package alx-platform -- --check`.
The checker proves that the command selects the named root package and every
literal in-root workspace member exactly once. It inventories owned manifests
and resolves internal dependency and override paths from their declaring
manifest. Direct external path dependencies receive only a bounded Cargo manifest
identity read to prove their workspace membership is separate; their dependencies
are never traversed. This also closes a preexisting isolated-package proof gap:
a sibling with an explicit workspace redirect could otherwise introduce a hidden
internal automatic member. Identity reads are deduplicated and capped at
256 manifests, 4 MiB aggregate and 1 MiB per file; uncertainty refuses selection.

The full `cargo fmt --all -- --check` lane and the isolated single-package lane
remain supported. Incomplete, foreign or duplicate selectors, hidden internal
packages, duplicate members/names, workspace redirects, glob members,
excludes/default-members, links and unprovable input boundaries refuse the
explicit-selector alternative. Virtual workspaces continue to require the full
lane. Compilation, Clippy, structural hygiene, tests and rustdoc are unchanged.

The Rust design contract, requirement, ADR, command diagnostic and public
standard summary describe the same scope. The focused formatter suite has
90 outcomes, including 23 workspace outcomes, 20 external-identity outcomes and
two Python 3.12 resolve-loop controls; five link cases require
symlink privileges and skip on Windows when unavailable. The added cases are
filesystem-only and require no compiler or network. External identity checks add
only the bounded direct manifest reads above, with no Cargo subprocess. Historical focused timing
grew from 1.34 s to 1.445 s for the workspace candidate, then 1.82 s with the
external identity controls; these are local observations, not benchmark claims.

Release qualification also retains the inherited CA remediation in the
2026.10.22 changelog. The copy-owned Lit template advances Vite to 8.3.5 and
Vitest to 5.0.5; its Undici resolution advances to 8.12.3. The TypeSpec template
advances its existing Undici override to 7.30.1 and fast-uri resolution to
3.1.9. These are patch/security updates needed for the unchanged dependency
audit gates; both template audits report zero vulnerabilities. No audit threshold
or runtime contract is relaxed. Copied downstream templates remain owner-managed
and do not update automatically when this package is installed.

Local Windows qualification on Python 3.14.6, uv 0.13.4 and Node 24.22.1 passed
the full governance audit and Rack suite: 36/36 subtests, 524 tests passed,
zero failures and six conditional link-privilege skips in 157.45 s. Both source
templates passed clean installation and signoff. The wheel and source
distribution built successfully, passed Twine, and passed isolated installed-wheel
template-copy/audit smoke checks. The installed wheel also accepts the actual
ALX two-package formatter command. Public PR CI and release publication are
verified separately; these local results do not claim a published package.
