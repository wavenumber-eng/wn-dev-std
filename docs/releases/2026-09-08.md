# 2026-09-08

Release version: `2026.9.8`

## Changes

- Generated governance pages now rewrite local Markdown links relative to the
  generated page instead of preserving paths relative to the source document.
- Links between governance records resolve to generated HTML pages, while
  ordinary repository links continue to target their authoritative source.
- Typed metadata references receive the same governance-page resolution.
- ADR and requirement `README.md` index pages are no longer misclassified as
  raw governance records by the HTML link policy.

## Validation

- Governance-link unit and integration tests cover record links, ordinary
  repository links, metadata references, embedded plan-log links, query and
  fragment suffixes, and README indexes.
- Full Rack signoff, package build, Twine validation, and installed-wheel smoke
  testing are required before publication.
