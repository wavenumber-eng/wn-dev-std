# 2026-09-06

Release version: `2026.9.6`

## Changes

- Resolves issue #30 by allowing governed `build`, `test`, and `signoff`
  command roles to use validated repository-relative file paths while
  preserving profile defaults.
- Separates command entrypoints from structural root requirements and reports
  invalid, missing, directory, absolute, traversal, and out-of-repository paths
  through one actionable diagnostic.
- Adds `dev-std plan close <plan-id>` as the canonical closeout checklist for
  agents and users. The command reports unfinished steps, unmet exit criteria,
  dependent plans, and the durable-record requirement without changing files.
- Adds explicit `dev-std plan close <plan-id> --delete` removal for ready plans;
  it deletes only the selected plan and attached logs and directs the caller to
  rerun the `docs.plans` audit.

- Ruff, formatting, Pyright, lock, documentation-contract, and Python hygiene

- The source distribution and universal wheel build successfully, and Twine
